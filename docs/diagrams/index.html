为什么要有这个页面？
这些图是真实的 PNG 文件，放在 docs/diagrams/ 目录下。 开发计划.md 第四章用相对路径引用它们（![](docs/diagrams/xx.png)）， 但网页版 Markdown 工具（语雀 / 飞书 / Notion 等）不会解析相对路径，所以那边看不到图。
本页面直接用文件名加载图片，用浏览器打开就一定能看到。也可以直接用文件管理器打开 docs/diagrams/ 目录，逐个双击 PNG。
